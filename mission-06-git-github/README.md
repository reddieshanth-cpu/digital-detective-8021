## 3. Commands / tools used

| Git command | Purpose |
|---|---|
| `git status` | Checks the current repository status. |
| `git add` | Stages selected changes for a commit. |
| `git commit` | Saves staged changes in the repository history. |
| `git log` | Displays previous commits. |
| `git branch` | Creates or lists branches. |
| `git switch` | Switches from one branch to another. |
| `git push` | Publishes local commits to GitHub. |
| `git pull` | Retrieves and integrates changes from the remote repository. |

## 4. My understanding

Git is a version control system that tracks changes in files. GitHub is an online platform where Git repositories can be hosted and shared.

Staging means selecting the changes that should be included in the next commit. Committing saves those staged changes as a version in the repository history.

A branch is a separate line of development that allows us to make changes without directly modifying the main branch.

A Pull Request is a request to review and merge changes from one branch into another. It helps team members review work, discuss changes and collaborate safely.
