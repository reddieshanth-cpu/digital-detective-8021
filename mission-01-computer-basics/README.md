# Mission 1 — Know Your Computer

## 1. Task / Objective

The objective of this mission was to understand how a computer receives input, processes information, produces output and stores data. It also involved identifying hardware, software and everyday computer-based systems.

## 2. Work Completed

- Studied the IPOS cycle.
- Traced the activity of typing and saving a document.
- Identified four hardware components.
- Identified four software examples.
- Classified software into operating system, application and utility software.
- Listed three computer-based systems used in everyday life.

### Task 1.1 — IPOS

| Stage | What happens | Hardware |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The processor processes the typed information. | CPU and RAM |
| Output | The document appears on the screen. | Monitor |
| Storage | The document is saved for future use. | SSD |

When I type a document, the keyboard sends input to the computer. The CPU processes the information and displays it on the screen. When I save the document, it is stored on the SSD so I can access it later.
