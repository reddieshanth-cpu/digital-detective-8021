### Task 4.2 — Compiler and Interpreter Comparison

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Before execution | During execution |
| Typical output | Translated code or executable | Executes instructions at runtime |
| One example | C compiler | Python interpreter |
| One advantage | Can produce fast executable programs | Useful for testing and interactive execution |

### Explanation

A compiler translates the source program into another form before execution. An interpreter executes program instructions at runtime.

A compiler can produce an executable program, while an interpreter makes it convenient to run and test code. Both approaches help computers execute programming instructions.
