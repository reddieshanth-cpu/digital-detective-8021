# The Digital Detective

## About This Project
The Digital Detective is an independent learning assignment that explores how computers work, how operating systems manage files and programs, how data is represented, and how computers communicate through networks.

This project includes practical activities, Terminal commands, Python programs, Git and GitHub exercises, and notes from each mission.

## Topics Covered

- Computer fundamentals and IPOS
- Hardware and software
- Terminal and command-line operations
- Operating systems and file permissions
- Compilers and interpreters
- Binary, decimal and hexadecimal number systems
- Python programming
- ASCII and UTF-8 encoding
- Git and GitHub
- Computer networking

## Running the Number Converter

Open Terminal inside the project folder and run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

## Learning Summary

Through this assignment, I aim to understand computer fundamentals, practise command-line operations, learn Python number conversions, and understand version control and computer networking.

Each mission is documented separately and committed to GitHub as part of the learning process.
