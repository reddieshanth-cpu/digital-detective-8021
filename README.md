# The Digital Detective — Diwali Independent Learning Assignment

## Project Overview

This repository contains my work for **The Digital Detective**, a Diwali independent learning assignment. The objective was to explore computer fundamentals, practise Terminal commands, understand operating systems and program execution, learn number systems, use Git and GitHub, and explore basic computer networking.

The assignment is organised into nine missions. Each mission has its own folder and README file documenting the activities, commands, observations and concepts learned.

## Topics Explored

- Computer fundamentals and the IPOS cycle.
- Hardware, software and everyday computer systems.
- Terminal commands, file management, flags and pipes.
- Operating systems, processes, paths and file permissions.
- Compilers, interpreters and Python program execution.
- Binary, decimal and hexadecimal number systems.
- ASCII and UTF-8 character encoding.
- Python number conversion.
- Git, GitHub, commits, branches and Pull Requests.
- LAN, MAN, WAN, DNS, routers, protocols and packet switching.
- Client-server communication and how websites work.

## Running the Python Number Converter

The number converter is available inside the Mission 5 folder.

Open Terminal in the repository directory and run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter a decimal number when prompted. The program displays its binary and hexadecimal representations.

## What I Learned

Through these missions, I learned how computers process and store information, how to work with files using Terminal, and how operating systems manage resources. I also practised writing and running a Python program, converting numbers between different number systems, and understanding character encoding.

I gained practical experience using Git and GitHub to track changes, create branches, publish work and create a Pull Request. I also learned how computers communicate over networks and how DNS helps locate websites.

## Repository Organisation

The repository also contains an `evidence` folder for supporting material and a `terminal-practice` folder containing Terminal exercises.
