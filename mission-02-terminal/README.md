## 4. My Understanding

### Task 2.2 — Answers

| Question | Answer |
|---|---|
| Difference between `>` and `>>` | `>` replaces file contents, while `>>` adds text at the end. |
| Copy vs move | Copy creates another file; move transfers or renames a file. |
| What does `pwd` provide? | It displays the current working directory. |
| Why is `ls` useful? | It helps us see files and folders in a directory. |

A pipe connects the output of one command to another command. Flags change how commands behave.
